# counselor-skill

> 一个面向 Claude Code 的心理咨询 skill：**可切换人格 + 可组合咨询方法**，把「谁在说」和「说什么」解耦。

> ⚠️ **免责声明**：这是自我帮助 / 心理教育工具，**不是**专业心理治疗，也**不能**用于诊断。若你或身边的人处于危机状态，请寻求专业帮助 —— 中国大陆可拨打 `010-82951332`（北京心理危机研究与干预中心）或当地急救电话。

## 特性

- **人格与方法解耦**：人格只决定「怎么说」，方法只决定「说什么」，可自由组合。
- **多人格**：默认雌小鬼，另含冷静分析师、温柔倾听者、直球教练，可随时切换。
- **多方法**：CBT 认知行为疗法、认知解离、暴露疗法、苏格拉底式提问、行为激活。
- **渐进式加载**：`SKILL.md` 只负责调度，人格与方法文件按需读取，不一次性灌满上下文。
- **会话记忆**：最小化记录咨询线索（用户画像 / 会话日志 / 关键洞察），支持手动瘦身。
- **安全底线**：危机场景强制切严肃模式并给出危机资源；记忆使用遵守「记忆是底牌，不是台词」。

## 安装

克隆到 Claude Code 的 skills 目录（文件夹名用 `counselor`）：

```bash
git clone https://github.com/cha0s3927/counselor-skill.git ~/.claude/skills/counselor
```

或手动把本仓库内容复制到 `~/.claude/skills/counselor/`，确保文件夹内直接是 `SKILL.md`。

重启 Claude Code 后，用 `/counselor` 调用。

## 使用

- 直接输入 `/counselor`
- 切换人格：「换个人格」「用温柔点的」「今天用直球教练」
- 指定方法：「今天用 CBT」「用认知解离」
- 记录 / 瘦身：「存档」「瘦身一下」

## 扩展

### 新增人格

在 `personas/` 下新建 `xxx.md`，**只写「怎么说话」**（语气、称呼、性格、反应、弱点），不要写咨询技术；然后在 `SKILL.md` 的人格表里登记。

### 新增方法

在 `methods/` 下新建 `xxx.md`，写清「适用场景 / 步骤 / 话术示例 / 注意事项」；然后在 `SKILL.md` 的方法表里登记。

## 设计原则

- **机制用 Claude 的，内容保持平台无关**：正文是纯 Markdown，换平台也能搬。
- **人格与方法解耦**：两者都是「菜单 + 默认 + 可点名」，选中才按需加载。
- **记忆薄而软**：存线索不存档案，弱标签、可删除、克制使用。
- **安全优先**：危机处理放在调度层，能压过任意人格。
