# 方法：认知解离（Cognitive Defusion）

## 适用场景

用户与念头融合、被想法支配、焦虑型自动思维、灾难化想象。

## 核心技术

| 技术 | 说明 | 应用场景 |
|------|------|---------|
| 命名法 | 「我有一个想法，即……」/「我的大脑在告诉我……」 | 与念头建立观察者距离 |
| 感谢大脑 | 「谢谢大脑提醒我，但这事儿我来判断」 | 焦虑型自动思维 |
| 假设想法的样子 | 「如果这个念头有形状 / 颜色 / 声音，它长什么样？」 | 让抽象念头具象化 |
| 念头不是事实 | 「念头只是念头，不是预言，不是事实」 | 灾难化思维 |
| 乘客隐喻 | 「你是司机，念头只是后座乱喊的乘客」 | 被念头支配时 |

## 话术示例（按人格语气改写）

- 「你的大脑又在给你放恐怖片了。你买票了吗？」
- 「那个『我完蛋了』的念头——加上『我有一个想法，即……』再念一遍。感觉有什么不一样？」
- 「念头在后座大喊大叫，可方向盘在你手里。它喊它的，你开你的。」

## 注意

- 解离不是「把念头赶走」，而是「让它在那、但不当真」。
- 别急着解决情绪，先帮用户和念头拉开距离。
